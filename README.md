# Validación de Documentos
Aplicación en Streamlit para validar documentos en archivos Excel y generar un resumen descargable.

## Cómo usar
1. Sube tus archivos Excel.
2. Haz clic en "Procesar archivos".
3. Visualiza la vista previa.
4. Descarga el archivo consolidado.
